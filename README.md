# Эйдос: Контур Обороны

Оригинальная минимальная Tower Defense игра в техно-научно-фантастическом стиле. Работает полностью в браузере без сборки и внешних зависимостей.

## Возможности

- волны с тремя классами противников;
- три башни: импульсная, замедляющая и с уроном по области;
- размещение мышью или касанием и четыре уровня улучшений;
- энергия, здоровье ядра, бонусы за волну;
- автоматическое сохранение прогресса в `localStorage`;
- адаптивный интерфейс.

## Запуск

Откройте `index.html` напрямую или запустите любой статический сервер, например:

```bash
python3 -m http.server 8080
```

Игра готова для GitHub Pages: публикуйте корень ветки `main`; файл `.nojekyll` уже добавлен.

## Управление

- `1`, `2`, `3` — выбрать тип башни;
- клик/касание свободной зоны — установить башню;
- клик по башне — выбрать для улучшения;
- `Esc` — отменить выбор.

## v2.0 — «Звёздный витраж» (19.10.2026)
- Новое яркое оформление: туманность, кристаллическая платформа, золотой энергоканал с бегущим светом, портал и пульсирующее ядро-кристалл с кольцом здоровья.
- На телефоне поле развёрнуто вертикально и занимает почти весь экран; арсенал и кнопки — в нижней панели. Сохранённые башни остаются на своих местах.
- Башни поворачиваются к цели, светятся, показывают уровень звёздами; у врагов глаза, свечение, вспышки попаданий, полоски здоровья, всплывающие «+энергия».
- **Орбитальный удар** ☄ (перезарядка 30 с) — удар по выбранной точке.
- **Тесла** теперь бьёт настоящим цепным разрядом, **Призма** пробивает всех врагов на линии.
- **Золотые дроны** (×5 энергии), **досрочный вызов волны** с бонусом, **автоволна**, скорость ×3.
- **Задания дня** 📜 с наградами.
- Убран раздел «Образы и оформление». Кнопка «Удобство» (◈) перенесена в верхнюю панель.
- Тест: `node tools/e2e-v2.js`.

## v3.0 — «Звёздные врата»
- Титульный экран с анимированной галактикой и выбором сектора.
- 4 сектора с разными картами и палитрами: Орбита Эйдос, Розовая туманность, Ледяная луна, Солнечная кузня. Сектор открывается волной 6 в предыдущем; звёзды за волны 5/10/15; у каждого сектора свой прогресс.
- Новые враги: Щитоносец (энергощит), Раскольник (делится на двух малышей), Целитель (лечит соседей).
- Пятый «звёздный» уровень башен.
- Старое сохранение автоматически переносится в сектор «Орбита» (ключ `eidos-defense-v2`, старый ключ не трогается).
