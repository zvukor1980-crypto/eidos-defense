# Эйдос: Контур Обороны

Оригинальная минимальная Tower Defense игра в техно-научно-фантастическом стиле. Работает полностью в браузере без сборки и внешних зависимостей.

## Возможности

- волны с тремя классами противников;
- три башни: импульсная, замедляющая и с уроном по области;
- размещение мышью или касанием и четыре уровня улучшений;
- энергия, здоровье ядра, бонусы за волну;
- автоматическое сохранение прогресса в `localStorage`;
- адаптивный интерфейс.

## Запуск

Откройте `index.html` напрямую или запустите любой статический сервер, например:

```bash
python3 -m http.server 8080
```

Игра готова для GitHub Pages: публикуйте корень ветки `main`; файл `.nojekyll` уже добавлен.

## Управление

- `1`, `2`, `3` — выбрать тип башни;
- клик/касание свободной зоны — установить башню;
- клик по башне — выбрать для улучшения;
- `Esc` — отменить выбор.
